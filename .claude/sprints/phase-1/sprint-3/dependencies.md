## API Contracts (for parallel dev)

### POST /api/actions/onboarding.start
Already live from P1-S1-BE-04. FE-01 calls this directly.

Request:
```json
{
  "blockId": "uuid",
  "payload": {
    "clientName": "string",
    "jurisdiction": "AU | UK | US | SG"
  }
}
```

Response (201):
```json
{
  "data": {
    "actionId": "uuid",
    "eventId": "uuid",
    "workflowJobId": "uuid",
    "status": "pending"
  },
  "error": null
}
```

Error (403 — compliance-approver blocked):
```json
{
  "error": { "code": "FORBIDDEN", "message": "Your role does not permit this action." }
}
```
