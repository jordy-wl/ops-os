## Blocker Protocol

If a dependency is not delivered on time:
1. Log a blocker immediately in `shared-state.md` Blockers table
2. Tag the blocking task's owner
3. If blocked for >4 hours: escalate to orchestrator
4. Do not sit idle — pick up the next unblocked task in your role's task file
